# functionsStyleguide

<!-- badges: start -->

<!-- badges: end -->

Das Package **functionsStyleguide** enthält die Farbpalette gemäss
Styleguide des Amts für Daten und Statistik sowie Funktionen für
ggplot-Grafiken gemäss Styleguide für verschiedene Grafiktypen. Im Ordner data sind 
einige Testdatensätze abgespeichert, mittels welcher die Beispiel-Codes getestet werden 
können.

## Installation über Github

``` r
# install.packages("devtools")
devtools::install_github("ogdtg/functionsStyleguide")
```
