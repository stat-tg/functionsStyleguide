ggplot_column {functionsStyleguide}R Documentation

Säulendiagramm erstellen

Description

Erstellt ein Säulendiagramm mit anpassbaren Füll- und Randfarben sowie optionaler Kategorisierung über eine Füllvariable. Die Werte werden auf der numerischen Achse mit Tausendertrennzeichen dargestellt.

Usage

ggplot_column(
  data,
  y,
  x,
  fill = NULL,
  color = NULL,
  title = NULL,
  subtitle = NULL,
  source = NULL,
  fill_color = 1,
  border_color = 1
)

Arguments

data

Ein Data Frame mit den darzustellenden Daten.

y

Name der numerischen Variable für die Säulenhöhe als Zeichenkette.

x

Name der kategorialen Variable auf der horizontalen Achse als Zeichenkette.

fill

Optionale kategoriale Variable zur Zuordnung der Füllfarben, angegeben als Zeichenkette. Wenn NULL, wird eine einheitliche Füllfarbe verwendet.

color

Optionale Variable zur Zuordnung der Randfarben als Zeichenkette. In der aktuellen Implementierung wird dieses Argument nicht für die Farbzuweisung verwendet.

title

Titel des Diagramms.

subtitle

Untertitel des Diagramms.

source

Quelle der dargestellten Daten. Wird in der Bildunterschrift zusammen mit dem Hinweis auf das Amt für Daten und Statistik Thurgau ausgegeben.

fill_color

Index der Füllfarbe aus maincolors_discrete$fillColor, wenn keine Füllvariable angegeben ist. Standardmässig 1.

border_color

Index der Randfarbe aus border_discrete$borderColor. Standardmässig 1.

Details

Wenn eine Füllvariable angegeben wird, werden die Säulen anhand ihrer Kategorien eingefärbt. Andernfalls erhalten alle Säulen eine einheitliche Füllfarbe. Die Randfarbe kann unabhängig davon festgelegt werden.

Value

Ein ggplot-Objekt, das weiter angepasst oder mit print() ausgegeben werden kann.

Examples

## Not run: 
# Einfaches Säulendiagramm
ggplot_column(
  data = tab_bev |> dplyr::mutate(jahr = as.character(jahr)),
  x = "jahr",
  y = "n",
  title = "Bevölkerungsentwicklung",
  subtitle = "Bevölkerung nach Jahr",
  source = "Kantonale Bevölkerungsstatistik",
  fill_color = 1,
  border_color = 1
)

## End(Not run)
