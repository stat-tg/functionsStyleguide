def_angle_map_sf {functionsStyleguide}R Documentation

Vorbereitungsfunktion für grafische Darstellung von Gemeindedaten als Karte

Description

Mit dieser Funktion werden die Gemeindelabels auf kartografischen Darstellungen vorbereitet, sodass deren Ausrichtung eine bestmögliche Lesbarkeit garantiert. Die Funktion muss nicht separat ausgeführt werden, sondern wird innerhalb der Funktion ggplot_map verwendet.

Usage

def_angle_map_sf(data)

Arguments

data

Daten

Value

Definition der Ausrichtung der Gemeindelabels für Karten
