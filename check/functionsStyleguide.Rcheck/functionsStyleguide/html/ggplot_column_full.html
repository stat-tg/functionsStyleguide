ggplot_column_full {functionsStyleguide}R Documentation

Säulendiagramm mit optionaler Gruppierung und Beschriftung erstellen

Description

Erstellt ein Säulendiagramm mit anpassbaren Füll- und Randfarben, optionaler Gruppierung, konfigurierbarer Reihenfolge der Kategorien sowie optionalen Wertbeschriftungen. Unterstützt gestapelte und nebeneinander angeordnete Säulen.

Usage

ggplot_column_full(
  data,
  y,
  x,
  fill = NULL,
  color = NULL,
  order = NULL,
  fill_palette = maincolors_discrete,
  fill_palette_name = "fillColor",
  fill_colors = NULL,
  fill_reverse = FALSE,
  border_palette = border_discrete,
  border_palette_name = "borderColor",
  border_colors = NULL,
  border_reverse = FALSE,
  fill_color = 1,
  border_color = 1,
  labels = FALSE,
  label_color = "white",
  label_size = 4.5,
  label_fontface = "bold",
  label_angle = 0,
  label_hjust = NULL,
  label_vjust = NULL,
  title = NULL,
  subtitle = NULL,
  source = NULL,
  position = "stack",
  reverse_stack = TRUE
)

Arguments

data

Ein Data Frame, der die darzustellenden Variablen enthält.

y

Ein Zeichenwert mit dem Namen der numerischen Variable, die auf der y-Achse dargestellt wird.

x

Ein Zeichenwert mit dem Namen der Variable, die auf der x-Achse dargestellt wird.

fill

Optionaler Zeichenwert mit dem Namen der Variable, nach der die Säulen eingefärbt werden. Bei NULL erhalten alle Säulen dieselbe Füllfarbe.

color

Optionaler Zeichenwert mit dem Namen der Variable, nach der die Randfarben der Säulen bestimmt werden. Bei NULL erhalten alle Säulen dieselbe Randfarbe.

order

Optionaler Zeichenwert mit dem Namen einer Variable, nach der die Kategorien von fill sortiert werden. Die Reihenfolge wird aufsteigend nach dieser Variable bestimmt.

fill_palette

Ein Palettenobjekt mit den verfügbaren Füllfarben. Standardmässig wird maincolors_discrete verwendet.

fill_palette_name

Ein Zeichenwert mit dem Namen des Eintrags in fill_palette, aus dem die Farben ausgewählt werden. Standardmässig "fillColor".

fill_colors

Optionaler Vektor mit explizit vorgegebenen Füllfarben für die Kategorien von fill. Wird an scale_fill_custom() übergeben.

fill_reverse

Logischer Wert. Bei TRUE wird die Reihenfolge der Füllfarben umgekehrt. Standardmässig FALSE.

border_palette

Ein Palettenobjekt mit den verfügbaren Randfarben. Standardmässig wird border_discrete verwendet.

border_palette_name

Ein Zeichenwert mit dem Namen des Eintrags in border_palette, aus dem die Randfarben ausgewählt werden. Standardmässig "borderColor".

border_colors

Optionaler Vektor mit explizit vorgegebenen Randfarben für die Kategorien von color. Wird an scale_colour_custom() übergeben.

border_reverse

Logischer Wert. Bei TRUE wird die Reihenfolge der Randfarben umgekehrt. Standardmässig FALSE.

fill_color

Index oder Indizes zur Auswahl bestimmter Füllfarben aus der gewählten Palette, wenn fill = NULL. Standardmässig 1.

border_color

Index oder Indizes zur Auswahl bestimmter Randfarben aus der gewählten Palette, wenn color = NULL. Standardmässig 1.

labels

Logischer Wert. Bei TRUE werden die Werte innerhalb der Säulen angezeigt. Standardmässig FALSE.

label_color

Farbe der Wertbeschriftungen. Standardmässig "white".

label_size

Schriftgrösse der Wertbeschriftungen. Standardmässig 4.5.

label_fontface

Schriftstil der Wertbeschriftungen, beispielsweise "plain", "bold" oder "italic". Standardmässig "bold".

label_angle

Winkel der Wertbeschriftungen in Grad. Standardmässig 0.

label_hjust

Optionale horizontale Ausrichtung der Wertbeschriftungen. Bei NULL wird die Ausrichtung abhängig von der Darstellung automatisch festgelegt.

label_vjust

Optionale vertikale Ausrichtung der Wertbeschriftungen. Bei NULL wird der Standardwert der Funktion verwendet.

title

Optionaler Titel des Diagramms.

subtitle

Optionaler Untertitel des Diagramms.

source

Optionale Angabe der Datenquelle, die in der Bildlegende unterhalb des Diagramms angezeigt wird.

position

Anordnung der Säulen. "stack" stapelt die Kategorien, "dodge" stellt sie nebeneinander dar. Standardmässig "stack".

reverse_stack

Logischer Wert. Bei TRUE wird die Reihenfolge der Segmente innerhalb gestapelter Säulen umgekehrt. Standardmässig TRUE.

Details

Die Funktion verwendet theme_bar_grid_horizontal() für die Diagrammgestaltung und formatiert numerische Achsenbeschriftungen mit einem Apostroph als Tausendertrennzeichen.

Wenn fill angegeben wird, werden die Füllfarben anhand der Kategorien dieser Variable zugewiesen. Wenn color angegeben wird, werden die Randfarben unabhängig davon anhand der entsprechenden Kategorien zugewiesen.

Mit position = "stack" werden die Kategorien gestapelt dargestellt. Mit position = "dodge" werden die Kategorien nebeneinander angeordnet. Wertbeschriftungen können mit labels = TRUE aktiviert werden.

Value

Ein ggplot-Objekt.

Examples

## Not run: 
# Einfaches Säulendiagramm mit Wertbeschriftungen
ggplot_column_full(
  data = tab_bev,
  y = "n",
  x = "jahr",
  title = "Bevölkerungsentwicklung",
  source = "Kantonale Bevölkerungsstatistik",
  labels = TRUE
)

# Gestapeltes Säulendiagramm nach Alterskategorie
ggplot_column_full(
  data = tab_alterskat,
  y = "n",
  x = "jahr",
  fill = "alterskat_det",
  color = "alterskat_det",
  fill_palette = colors_sequential,
  fill_palette_name = "fillSeq5",
  border_palette = border_sequential,
  border_palette_name = "borderSeq5",
  position = "stack",
  labels = TRUE
)

## End(Not run)
