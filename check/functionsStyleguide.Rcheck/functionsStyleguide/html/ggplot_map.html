ggplot_map {functionsStyleguide}R Documentation

Gemeindekarte mit kategorisierten Werten erstellen

Description

Erstellt eine thematische Karte der Gemeinden des Kantons Thurgau. Die Gemeinden werden anhand einer numerischen oder kategorialen Variable in Kategorien eingeteilt und entsprechend eingefärbt. Die Farbpalette, die Zuordnung der Farben zu den Kategorien sowie die Beschriftungen der Legende können individuell angepasst werden.

Usage

ggplot_map(
  data,
  var_bfs = "bfs_nr",
  var_gemeinde = "gemeinde",
  var_jahr = NULL,
  var_value,
  label_value = NULL,
  palette = maincolors_discrete,
  palette_name = "fillColor",
  colors = NULL,
  reverse = FALSE,
  category_labels = NULL,
  legend_ncol = 2,
  title = NULL,
  subtitle = NULL,
  source = NULL
)

Arguments

data

Ein Data Frame mit den darzustellenden Gemeindedaten.

var_bfs

Zeichenkette mit dem Namen der Variable, welche die BFS-Gemeindenummer enthält. Standardmässig "bfs_nr".

var_gemeinde

Zeichenkette mit dem Namen der Gemeindevariable. Standardmässig "gemeinde".

var_jahr

Optionaler Name der Jahresvariable. Wird auf ihre Existenz im Datensatz geprüft. Standardmässig NULL.

var_value

Zeichenkette mit dem Namen der Variable, deren Werte auf der Karte dargestellt und für die Beschriftungsfarbe verwendet werden.

label_value

Optionale Beschriftung des dargestellten Wertes. Standardmässig NULL.

palette

Farbpalette als Liste, aus der die Farben ausgewählt werden. Standardmässig maincolors_discrete.

palette_name

Zeichenkette mit dem Namen des Palettenelements, das verwendet werden soll. Standardmässig "fillColor".

colors

Optionaler numerischer Vektor mit den Indizes der Farben, die aus dem gewählten Palettenelement ausgewählt werden sollen. Die Indizes müssen gültige positive ganze Zahlen innerhalb der verfügbaren Palette sein. Standardmässig NULL.

reverse

Logischer Wert. Wenn TRUE, wird die Reihenfolge der ausgewählten Farben umgekehrt. Standardmässig FALSE.

category_labels

Optionaler Zeichenvektor mit den Bezeichnungen der Kategorien für die Legende. Muss bei Angabe genau so viele Elemente enthalten, wie Kategorien vorhanden sind. Standardmässig NULL; in diesem Fall werden die Kategorien selbst als Bezeichnungen verwendet.

legend_ncol

Anzahl der Spalten in der Kartenlegende. Muss eine positive ganze Zahl sein. Standardmässig 2.

title

Optionaler Titel der Karte. Standardmässig NULL.

subtitle

Optionaler Untertitel der Karte. Standardmässig NULL.

source

Optionale Angabe der Datenquelle. Wird in der Bildunterschrift zusammen mit dem Hinweis auf das Amt für Daten und Statistik Thurgau ausgegeben. Standardmässig NULL.

Details

Die Gemeindekarte basiert auf einem räumlichen sf-Datensatz. Die übergebenen Daten werden anhand der Gemeindeinformationen mit den Kartengeometrien verknüpft. Die Beschriftungen und ihre Positionen werden automatisch mithilfe vorbereiteter Koordinaten und Drehwinkel ermittelt.

Die Gemeindekartengeometrien werden aus der Datei "data/maps/Gemeinden_TG.shp" geladen. Diese Datei muss unter dem angegebenen relativen Pfad verfügbar sein.

Die Daten werden über die Gemeindevariable mit den Kartengeometrien verknüpft. Die BFS-Nummer wird als Eingabevariable geprüft, während die Standardisierung der Spaltennamen für die weitere Verarbeitung erfolgt. Die Jahresvariable wird, sofern angegeben, auf ihre Existenz geprüft, aber nicht für die Verknüpfung oder die Kartendarstellung verwendet.

Die Kategorien werden aus der Variable kategorie ermittelt und sortiert. Die Anzahl Gemeinden pro Kategorie wird in der Legende ergänzt. Nicht zugeordnete Kategorien werden bei der Zählung nicht berücksichtigt.

Die Farben stammen aus dem über palette_name ausgewählten Element von palette. Mit colors können gezielt Farben ausgewählt werden; mit reverse lässt sich ihre Reihenfolge umkehren. Die gewählte Palette muss mindestens so viele Farben enthalten, wie Kategorien dargestellt werden.

Value

Ein ggplot-Objekt mit der eingefärbten Gemeindekarte, den Gemeindebeschriftungen und einer Legende mit Kategorien und der jeweiligen Anzahl Gemeinden.

Examples

## Not run: 
# Karte der Gemeindesteuerfüsse
ggplot_map(
  data = tab_steuerfuss,
  var_value = "gemeindesteuerfuss",
  label_value = "Gemeindesteuerfuss in %",
  palette = colors_divergent,
  palette_name = "fillDiv5",
  category_labels = c(
    "30–39 %",
    "40–49 %",
    "50–59 %",
    "60–69 %",
    "70–72 %"
  ),
  title = "Wenige Steuerfüsse über 70 %",
  subtitle = paste(
    "Kanton Thurgau, 2026,",
    "Gemeindesteuerfüsse nach Kategorien"
  ),
  source = "Steuerverwaltung Thurgau"
)

# Karte mit abweichenden Spaltennamen
ggplot_map(
  data = data_konf,
  var_gemeinde = "gemeinde_name",
  var_bfs = "bfs_nr_gemeinde",
  var_value = "prop_ev",
  label_value = "Anteil Evangelisch-reformiert",
  category_labels = c(
    "unter 10",
    "zwischen 10 und 20",
    "über 20"
  ),
  source = "Kantonale Bevölkerungsstatistik"
)

## End(Not run)
