ggplot_column_vi {functionsStyleguide}R Documentation

Horizontales Säulendiagramm mit optionalen Konfidenzintervallen erstellen

Description

Erstellt ein horizontales Säulendiagramm zur Darstellung numerischer Werte nach Kategorien. Die Balken können einheitlich eingefärbt oder anhand einer Gruppierungsvariable mit unterschiedlichen Füll- und Rahmenfarben dargestellt werden. Optional lassen sich Konfidenzintervalle ergänzen.

Usage

ggplot_column_vi(
  data,
  y,
  x,
  ci_lower = NULL,
  ci_upper = NULL,
  group = NULL,
  title = NULL,
  subtitle = NULL,
  source = NULL,
  fill_palette = maincolors_discrete,
  fill_palette_name = "fillColor",
  fill_color = NULL,
  fill_reverse = FALSE,
  border_palette = border_discrete,
  border_palette_name = "borderColor",
  border_color = NULL,
  border_reverse = FALSE,
  position = "dodge",
  errorbar_width = 0.2,
  x_expand = 0.1,
  y_label_wrap = NULL
)

Arguments

data

Ein Data Frame mit den darzustellenden Daten.

y

Zeichenkette mit dem Namen der kategorialen Variable für die Kategorienachse, beispielsweise eine Bildungs- oder Alterskategorie.

x

Zeichenkette mit dem Namen der numerischen Variable für die Balkenlängen.

ci_lower

Optionaler Name der Variable mit den unteren Grenzen der Konfidenzintervalle. Muss zusammen mit ci_upper angegeben werden. Standardmässig NULL.

ci_upper

Optionaler Name der Variable mit den oberen Grenzen der Konfidenzintervalle. Muss zusammen mit ci_lower angegeben werden. Standardmässig NULL.

group

Optionale Zeichenkette mit dem Namen der Gruppierungsvariable. Die Gruppen werden durch unterschiedliche Füll- und Rahmenfarben dargestellt. Standardmässig NULL.

title

Optionaler Titel des Diagramms. Standardmässig NULL.

subtitle

Optionaler Untertitel des Diagramms. Standardmässig NULL.

source

Optionale Angabe der Datenquelle. Wird in der Bildunterschrift zusammen mit dem Hinweis auf das Amt für Daten und Statistik ausgegeben. Standardmässig NULL.

fill_palette

Liste mit Farbpaletten für die Balkenfüllung. Standardmässig maincolors_discrete.

fill_palette_name

Zeichenkette mit dem Namen des Palettenelements, aus dem die Füllfarben ausgewählt werden. Standardmässig "fillColor".

fill_color

Optionaler Index oder Vektor von Indizes zur Auswahl bestimmter Füllfarben aus dem gewählten Palettenelement. Bei gruppierten Balken müssen genügend Farben für alle Gruppen vorhanden sein. Ohne Gruppierung wird nur die erste ausgewählte Farbe verwendet. Standardmässig NULL.

fill_reverse

Logischer Wert. Wenn TRUE, wird die Reihenfolge der ausgewählten Füllfarben umgekehrt. Standardmässig FALSE.

border_palette

Liste mit Farbpaletten für die Balkenrahmen. Standardmässig border_discrete.

border_palette_name

Zeichenkette mit dem Namen des Palettenelements, aus dem die Rahmenfarben ausgewählt werden. Standardmässig "borderColor".

border_color

Optionaler Index oder Vektor von Indizes zur Auswahl bestimmter Rahmenfarben aus dem gewählten Palettenelement. Bei gruppierten Balken müssen genügend Farben für alle Gruppen vorhanden sein. Ohne Gruppierung wird nur die erste ausgewählte Farbe verwendet. Standardmässig NULL.

border_reverse

Logischer Wert. Wenn TRUE, wird die Reihenfolge der ausgewählten Rahmenfarben umgekehrt. Standardmässig FALSE.

position

Positionierung der Balken. Erlaubt sind "dodge" für nebeneinander angeordnete Balken und "stack" für gestapelte Balken. Standardmässig "dodge". Bei gruppierten Balken mit Konfidenzintervallen ist ausschliesslich "dodge" zulässig.

errorbar_width

Breite der Markierungen der Konfidenzintervalle. Standardmässig 0.2.

x_expand

Relativer Zuschlag zum maximalen x-Wert, um zusätzlichen Platz am Ende der Wertachse zu schaffen. Beispielsweise entspricht 0.10 einem Zuschlag von 10 Prozent. Standardmässig 0.10.

y_label_wrap

Optionale maximale Zeilenbreite für die Beschriftungen der Kategorienachse. Wird an scales::label_wrap() übergeben. Bei NULL werden die Kategorien ohne zusätzliche Umbrüche dargestellt. Standardmässig NULL.

Details

Die Farben werden aus benutzerdefinierten Farbpaletten ausgewählt. Bei gruppierten Balken werden die Farben den Gruppen entsprechend ihrer Reihenfolge zugewiesen. Die Kategorienachse kann bei Bedarf mit Zeilenumbrüchen formatiert werden.

Die Funktion prüft, ob die angegebenen Variablen im Datensatz vorhanden sind. Die Variablen für die unteren und oberen Konfidenzintervallgrenzen müssen entweder beide angegeben werden oder beide fehlen.

Bei gruppierten Balken werden die Faktorlevels beziehungsweise die Reihenfolge der vorkommenden Gruppen zur Zuordnung der Farben verwendet. Die Füll- und Rahmenfarbpaletten müssen genügend Farben für alle Gruppen enthalten.

Die Wertachse beginnt bei null und endet beim maximalen Wert der oberen Konfidenzintervallgrenze, sofern diese angegeben ist, andernfalls beim maximalen Wert von x, jeweils erweitert um den Faktor 1 + x_expand. Die Achsenbeschriftungen verwenden Apostrophe als Tausendertrennzeichen.

Value

Ein ggplot-Objekt mit horizontal dargestellten Balken, optionalen Konfidenzintervallen, benutzerdefinierten Farbskalen und formatierter Beschriftung.

Examples

## Not run: 
# Balkendiagramm mit Konfidenzintervallen
ggplot_column_vi(
  data = tab_bildung_tot,
  y = "ausbildung_5cat",
  x = "anteil",
  ci_lower = "ci_l_pr",
  ci_upper = "ci_u_pr",
  title = "Bildung in der Bevölkerung",
  subtitle = "Kanton Thurgau",
  source = "Kantonale Bevölkerungsstatistik",
  fill_color = 2,
  border_color = 2,
  y_label_wrap = 20
)

# Gruppierte Balken nach Geschlecht mit Konfidenzintervallen
ggplot_column_vi(
  data = tab_bildung_sex_full,
  y = "ausbildung_5cat",
  x = "anteil",
  group = "sex",
  ci_lower = "ci_l_pr",
  ci_upper = "ci_u_pr",
  title = "Bildung nach Geschlecht",
  subtitle = "Kanton Thurgau",
  source = "Kantonale Bevölkerungsstatistik",
  y_label_wrap = 20
)

## End(Not run)
