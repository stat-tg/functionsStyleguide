ggplot_stacked_column {functionsStyleguide}R Documentation

Gestapeltes Säulendiagramm erstellen

Description

Erstellt ein gestapeltes Säulendiagramm auf Basis eines Datensatzes. Die Säulen können nach einer Kategorie eingefärbt und mit kategorienabhängigen Rahmenfarben versehen werden. Die Farben werden aus den definierten Farbpaletten maincolors_discrete$fillColor und border_discrete$borderColor ausgewählt.

Usage

ggplot_stacked_column(
  data,
  y,
  x,
  fill = NULL,
  color = NULL,
  title = NULL,
  subtitle = NULL,
  source = NULL,
  fill_color = 1,
  border_color = 1,
  position = "stack"
)

Arguments

data

Ein Data Frame mit den darzustellenden Daten.

y

Zeichenkette mit dem Namen der numerischen Variable für die Säulenhöhe.

x

Zeichenkette mit dem Namen der Variable für die x-Achse.

fill

Optionale Zeichenkette mit dem Namen der Variable, nach der die Säulenfüllung kategorisiert wird. Die Kategorien werden mit Farben aus maincolors_discrete$fillColor dargestellt.

color

Optionale Zeichenkette mit dem Namen der Variable, nach der die Rahmenfarben der Säulen kategorisiert werden. Die Kategorien werden mit Farben aus border_discrete$borderColor dargestellt.

title

Optionaler Titel des Diagramms.

subtitle

Optionaler Untertitel des Diagramms.

source

Optionale Angabe der Datenquelle. Wird in der Bildunterschrift zusammen mit dem Hinweis auf das Amt für Daten und Statistik Thurgau ausgegeben.

fill_color

Index der Farbe aus maincolors_discrete$fillColor, die verwendet wird, wenn fill = NULL. Standardmässig 1.

border_color

Index der Farbe aus border_discrete$borderColor, die verwendet wird, wenn color = NULL. Standardmässig 1.

position

Positionierungsverfahren für die Säulen, das an ggplot2::geom_col() übergeben wird. Standardmässig "stack" für gestapelte Säulen. Weitere mögliche Werte sind beispielsweise "dodge" für nebeneinander angeordnete Säulen.

Details

Über den Parameter position kann gesteuert werden, ob die Säulen gestapelt oder beispielsweise nebeneinander dargestellt werden. Titel, Untertitel und Datenquelle können optional angegeben werden.

Wenn fill angegeben ist, werden die Füllfarben den Kategorien entsprechend ihrer Reihenfolge im Datensatz beziehungsweise den Faktorlevels zugewiesen. Faktorlevels bleiben auch dann in der Farbskala erhalten, wenn sie in den dargestellten Daten nicht vorkommen.

Entsprechend werden bei Angabe von color die Rahmenfarben den Kategorien der angegebenen Variable zugewiesen. Sind mehr Kategorien vorhanden als Farben in der jeweiligen Palette, wird ein Fehler ausgelöst.

Wenn fill oder color nicht angegeben ist, wird eine feste Farbe anhand des jeweiligen Indexparameters verwendet.

Die y-Achse verwendet Tausendertrennzeichen mit Apostrophen und beginnt ohne zusätzlichen Abstand bei null. Auch die x-Achse erhält keinen zusätzlichen Rand. Die Formatierung wird durch theme_bar_grid_horizontal ergänzt.

Value

Ein ggplot-Objekt mit dem Säulendiagramm, der konfigurierten Farbgebung und der formatierten Beschriftung.

Examples

## Not run: 
ggplot_stacked_column(
  data = tab_alterskat |>
    dplyr::mutate(jahr = as.character(jahr)),
  x = "jahr",
  y = "n",
  fill = "alterskat",
  color = "alterskat",
  title = "Bevölkerung nach Alterskategorie",
  subtitle = "Entwicklung im Zeitverlauf",
  source = "Kantonale Bevölkerungsstatistik"
)

## End(Not run)
