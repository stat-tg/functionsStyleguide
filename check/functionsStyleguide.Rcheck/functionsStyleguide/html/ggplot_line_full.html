ggplot_line_full {functionsStyleguide}R Documentation

Vollständiges Liniendiagramm erstellen

Description

Erstellt ein Liniendiagramm mit anpassbaren Farben, optionaler Gruppierung und verschiedenen Beschriftungsmöglichkeiten. Die Funktion unterstützt sowohl eine einzelne Linie als auch mehrere Linien, die anhand einer Gruppierungsvariable dargestellt werden.

Usage

ggplot_line_full(
  data,
  y,
  x,
  group = NULL,
  color = NULL,
  order = NULL,
  group_palette = maincolors_discrete,
  group_palette_name = "fillHighlight",
  group_colors = NULL,
  group_reverse = FALSE,
  border_palette = border_discrete,
  border_palette_name = "borderHighligt",
  border_colors = NULL,
  border_reverse = FALSE,
  line_color = 1,
  y_min = NULL,
  y_max = NULL,
  theme = theme_opts_line,
  labels = FALSE,
  label_color = "white",
  label_size = 4.5,
  label_fontface = "bold",
  label_angle = 0,
  label_hjust = NULL,
  label_vjust = NULL,
  line_labels = FALSE,
  line_label_position = 0.5,
  line_label_size = 4,
  line_label_fontface = "bold",
  line_label_hjust = 0.5,
  line_label_vjust = -0.5,
  line_label_nudge_x = 0,
  line_label_nudge_y = 0,
  title = NULL,
  subtitle = NULL,
  source = NULL
)

Arguments

data

Ein Data Frame mit den darzustellenden Daten.

y

Name der numerischen Variable für die vertikale Achse als Zeichenkette.

x

Name der Variable für die horizontale Achse als Zeichenkette, beispielsweise eine Jahresvariable.

group

Optionale kategoriale Variable zur Gruppierung der Linien als Zeichenkette. Wenn NULL, wird eine einzelne Linie dargestellt, sofern auch color gleich NULL ist.

color

Optionale Variable zur Zuordnung der Linienfarben als Zeichenkette. Wenn NULL und group nicht NULL ist, werden die Gruppen anhand von group_palette eingefärbt.

order

Optionale Variable zur Festlegung der Reihenfolge der Gruppen als Zeichenkette. Die Gruppen werden anhand dieser Variable aufsteigend sortiert.

group_palette

Farbpalette für die Liniengruppen. Standardmässig wird maincolors_discrete verwendet.

group_palette_name

Name des Eintrags innerhalb von group_palette, aus dem die Linienfarben ausgewählt werden. Standardmässig "fillHighlight".

group_colors

Optionaler benannter Vektor mit benutzerdefinierten Farben für die Liniengruppen. Wird an scale_colour_custom() übergeben.

group_reverse

Logischer Wert. Wenn TRUE, wird die Reihenfolge der Gruppenfarben umgekehrt.

border_palette

Farbpalette für die Linienfarben, wenn eine separate Farbvariable über color angegeben wird. Standardmässig wird border_discrete verwendet.

border_palette_name

Name des Eintrags innerhalb von border_palette. Standardmässig "borderHighligt".

border_colors

Optionaler benannter Vektor mit benutzerdefinierten Farben für die Kategorien der Variable color. Wird an scale_colour_custom() übergeben.

border_reverse

Logischer Wert. Wenn TRUE, wird die Reihenfolge der Farben aus border_palette umgekehrt.

line_color

Index der Linienfarbe innerhalb von group_palette[[group_palette_name]], wenn weder group noch color angegeben ist. Standardmässig 1.

y_min

Optionale untere Grenze der vertikalen Achse. Wenn NULL, wird standardmässig 0 verwendet.

y_max

Optionale obere Grenze der vertikalen Achse. Wenn NULL, wird standardmässig das 1,1-Fache des grössten Wertes von y verwendet.

theme

ggplot2-Theme für die Gestaltung des Diagramms. Standardmässig theme_opts_line.

labels

Logischer Wert. Wenn TRUE, werden die numerischen Werte der Variable y direkt im Diagramm beschriftet.

label_color

Farbe der Wertbeschriftungen. Standardmässig "white".

label_size

Schriftgrösse der Wertbeschriftungen. Standardmässig 4.5.

label_fontface

Schriftstil der Wertbeschriftungen, beispielsweise "plain" oder "bold". Standardmässig "bold".

label_angle

Drehwinkel der Wertbeschriftungen in Grad. Standardmässig 0.

label_hjust

Horizontale Ausrichtung der Wertbeschriftungen. Wenn NULL, wird standardmässig 0.5 verwendet.

label_vjust

Vertikale Ausrichtung der Wertbeschriftungen. Wenn NULL, wird standardmässig -0.5 verwendet.

line_labels

Logischer Wert. Wenn TRUE, werden die Linien zusätzlich mit dem Namen ihrer Gruppenkategorie beschriftet. Dafür muss group angegeben sein.

line_label_position

Numerischer Wert zwischen 0 und 1, der die ungefähre Position der Linienbeschriftung entlang der jeweiligen Linie bestimmt. 0 entspricht dem Anfang und 1 dem Ende. Standardmässig 0.5.

line_label_size

Schriftgrösse der Linienbeschriftungen. Standardmässig 4.

line_label_fontface

Schriftstil der Linienbeschriftungen. Standardmässig "bold".

line_label_hjust

Horizontale Ausrichtung der Linienbeschriftungen. Standardmässig 0.5.

line_label_vjust

Vertikale Ausrichtung der Linienbeschriftungen. Standardmässig -0.5.

line_label_nudge_x

Numerische Verschiebung der Linienbeschriftungen in horizontaler Richtung. Standardmässig 0.

line_label_nudge_y

Numerische Verschiebung der Linienbeschriftungen in vertikaler Richtung. Standardmässig 0.

title

Titel des Diagramms.

subtitle

Untertitel des Diagramms.

source

Quelle der dargestellten Daten. Wird in der Bildunterschrift zusammen mit dem Hinweis auf das Amt für Daten und Statistik Thurgau ausgegeben.

Details

Die Reihenfolge der Gruppen kann über eine Sortiervariable gesteuert werden. Für die Linienfarben können benutzerdefinierte Farbpaletten verwendet werden. Zusätzlich lassen sich numerische Werte direkt im Diagramm anzeigen und die einzelnen Linien mit ihren Kategorienamen beschriften.

Die Grenzen der vertikalen Achse können über y_min und y_max festgelegt werden. Als Standard beginnt die Achse bei null und reicht bis 110 Prozent des grössten dargestellten Wertes.

Value

Ein ggplot-Objekt, das weiter angepasst oder mit print() ausgegeben werden kann.

Examples

## Not run: 
# Einzelne Linie mit benutzerdefinierter Achsenskalierung
ggplot_line_full(
  data = tab_bev,
  x = "jahr",
  y = "n",
  line_color = 1,
  title = "Bevölkerung",
  subtitle = "Entwicklung über die Zeit",
  source = "Kantonale Bevölkerungserhebung",
  y_min = 0,
  y_max = 350000
)

# Mehrere Linien mit Beschriftung der Kategorien
ggplot_line_full(
  data = tab_alterskat,
  x = "jahr",
  y = "n",
  order = "order",
  group = "alterskat_det",
  line_labels = TRUE,
  line_label_size = 4,
  line_label_nudge_x = 0.2,
  group_palette = colors_sequential,
  group_palette_name = "fillSeq5",
  title = "Bevölkerung nach Alterskategorie",
  subtitle = "Entwicklung über die Zeit",
  source = "Kantonale Bevölkerungserhebung"
)

## End(Not run)
