ggplot_bar {functionsStyleguide}R Documentation

Einfache Balkengrafik

Description

Funktion zur Darstellung von Daten als Balkengrafik mit ggplot2 gemäss dem Design Styleguide des Amts für Daten und Statistik

Usage

ggplot_bar(
  data,
  y,
  x,
  title = NULL,
  subtitle = NULL,
  source = NULL,
  fill_color = 1,
  border_color = 1,
  fill_colors = NULL,
  border_colors = NULL
)

Arguments

data

Datensatz, der als Balkengrafik dargestellt werden soll

y

Variable, die auf der y-Achse dargestellt werden soll

x

Variable, die auf der x-Achse dargestellt werden soll (bspw. das Jahr)

title

Titel

subtitle

Untertitel

source

Datenquelle

fill_color

Erlaubt die Auswahl einer Füllfarber aus der Palette mit den Hauptfarben #' maincolors_discrete$fillColor. Wird verwendet, wenn fill_colors auf NULL gesetzt ist. Default ist 1 sprich '#1D6AA22'.

border_color

Erlaubt die Auswahl einer Farbe für den Umriss aus der Palette mit den Hauptfarben border_discrete$borderColor. Wird verwendet, wenn border_colors auf NULL gesetzt ist. Default ist 1 resp. '#175582'.

fill_colors

Optionale Möglichkeit, die Füllfarben pro Balken zu wählen, bspw. um einen Balken speziell hervorzuheben. Balken ohne Definition entsprechen der ersten Farbe von fill_color.

border_colors

Optionale Möglichkeit, die Farben für die Umrisse pro Balken zu wählen, bspw. um einen Balken speziell hervorzuheben. Balken ohne Definition entsprechen der ersten Farbe von border_color.

Value

ggplot Balkengrafik

Examples

## Not run: 
# Use the default fill and border colours
ggplot_bar(
  data = tab_bev,
  x = "jahr",
  y = "n",
  title = "Bevölkerungsentwicklung"
)

# Specify individual fill and border colours
ggplot_bar(
  data = tab_bev,
  x = "jahr",
  y = "n",
  fill_colors = c(
    "2019" = "#4477AA",
    "2020" = "#EE6677",
    "2021" = "#228833"
  ),
  border_colors = c(
    "2019" = "#222222",
    "2020" = "#222222",
    "2021" = "#555555"
  )
)

## End(Not run)
