ggplot_line_vi {functionsStyleguide}R Documentation

Liniendiagramm mit Konfidenzintervallen erstellen

Description

Erstellt ein Liniendiagramm mit optionalen Konfidenzintervallen, anpassbaren Farbpaletten und zusätzlichen Beschriftungsmöglichkeiten. Die Funktion unterstützt einzelne Linien sowie mehrere nach Kategorien gruppierte Linien.

Usage

ggplot_line_vi(
  data,
  y,
  x,
  ci_lower = NULL,
  ci_upper = NULL,
  group = NULL,
  color = NULL,
  order = NULL,
  errorbar_width = 0.2,
  x_expand = 0.1,
  group_palette = maincolors_discrete,
  group_palette_name = "fillHighlight",
  group_colors = NULL,
  group_reverse = FALSE,
  border_palette = border_discrete,
  border_palette_name = "borderHighligt",
  border_colors = NULL,
  border_reverse = FALSE,
  line_color = 1,
  ribbon_alpha = 0.3,
  y_min = NULL,
  y_max = NULL,
  theme = theme_opts_line,
  labels = FALSE,
  label_color = "white",
  label_size = 4.5,
  label_fontface = "bold",
  label_angle = 0,
  label_hjust = NULL,
  label_vjust = NULL,
  line_labels = FALSE,
  line_label_position = 0.5,
  line_label_size = 4,
  line_label_fontface = "bold",
  line_label_hjust = 0.5,
  line_label_vjust = -0.5,
  line_label_nudge_x = 0,
  line_label_nudge_y = 0,
  title = NULL,
  subtitle = NULL,
  source = NULL
)

Arguments

data

Ein Data Frame mit den darzustellenden Daten.

y

Name der numerischen Variable für die vertikale Achse als Zeichenkette.

x

Name der Variable für die horizontale Achse als Zeichenkette, beispielsweise eine Jahresvariable.

ci_lower

Optionale Variable mit den unteren Grenzen der Konfidenzintervalle als Zeichenkette.

ci_upper

Optionale Variable mit den oberen Grenzen der Konfidenzintervalle als Zeichenkette.

group

Optionale kategoriale Variable zur Gruppierung der Linien als Zeichenkette. Wenn angegeben, erhält jede Gruppe eine eigene Linie und eine eigene Farbe.

color

Optionale Variable zur separaten Zuordnung der Linien- und Konfidenzintervallfarben als Zeichenkette. Wenn angegeben, werden die Farben anhand dieser Variable bestimmt.

order

Optionale Variable zur Festlegung der Reihenfolge der Gruppen als Zeichenkette. Die Gruppen werden anhand dieser Variable aufsteigend sortiert.

errorbar_width

Breite der Fehlerbalken. Dieses Argument ist in der aktuellen Implementierung nicht in der Darstellung eingebunden.

x_expand

Relativer Erweiterungsfaktor für die obere Grenze der horizontalen Achse. Der grösste Wert von ci_upper oder, falls nicht angegeben, von x wird um diesen Faktor erweitert. Standardmässig 0.10.

group_palette

Farbpalette für die Liniengruppen. Standardmässig wird maincolors_discrete verwendet.

group_palette_name

Name des Eintrags innerhalb von group_palette, aus dem die Gruppenfarben ausgewählt werden. Standardmässig "fillHighlight".

group_colors

Optionale numerische Indizes zur Auswahl bestimmter Farben aus der Gruppenpalette.

group_reverse

Logischer Wert. Wenn TRUE, wird die Reihenfolge der ausgewählten Gruppenfarben umgekehrt.

border_palette

Farbpalette für die Linienfarben, wenn eine separate Farbvariable über color angegeben wird. Standardmässig wird border_discrete verwendet.

border_palette_name

Name des Eintrags innerhalb von border_palette. Standardmässig "borderHighligt".

border_colors

Optionale numerische Indizes zur Auswahl bestimmter Farben aus der Randfarbpalette.

border_reverse

Logischer Wert. Wenn TRUE, wird die Reihenfolge der ausgewählten Randfarben umgekehrt.

line_color

Index der Linienfarbe innerhalb der ausgewählten Gruppenpalette, wenn weder group noch color angegeben ist. Standardmässig 1.

ribbon_alpha

Transparenz der Konfidenzintervallflächen. Zulässige Werte liegen zwischen 0 (vollständig transparent) und 1 (vollständig deckend). Standardmässig 0.30.

y_min

Optionale untere Grenze der vertikalen Achse. Wenn NULL, wird standardmässig 0 verwendet.

y_max

Optionale obere Grenze der vertikalen Achse. Wenn NULL, wird standardmässig das 1,1-Fache des grössten Wertes von y verwendet. In der aktuellen Implementierung werden anschliessend zusätzlich 10 Einheiten zur oberen Grenze addiert.

theme

ggplot2-Theme für die Gestaltung des Diagramms. Standardmässig theme_opts_line.

labels

Logischer Wert. Wenn TRUE, werden die numerischen Werte der Variable y direkt im Diagramm beschriftet.

label_color

Farbe der Wertbeschriftungen. Standardmässig "white".

label_size

Schriftgrösse der Wertbeschriftungen. Standardmässig 4.5.

label_fontface

Schriftstil der Wertbeschriftungen, beispielsweise "plain" oder "bold". Standardmässig "bold".

label_angle

Drehwinkel der Wertbeschriftungen in Grad. Standardmässig 0.

label_hjust

Horizontale Ausrichtung der Wertbeschriftungen. Wenn NULL, wird standardmässig 0.5 verwendet.

label_vjust

Vertikale Ausrichtung der Wertbeschriftungen. Wenn NULL, wird standardmässig -0.5 verwendet.

line_labels

Logischer Wert. Wenn TRUE, werden die Linien zusätzlich mit dem Namen ihrer Gruppenkategorie beschriftet. Dafür muss group angegeben sein.

line_label_position

Numerischer Wert zwischen 0 und 1, der die ungefähre Position der Linienbeschriftung entlang der jeweiligen Linie bestimmt. 0 entspricht dem Anfang und 1 dem Ende. Standardmässig 0.5.

line_label_size

Schriftgrösse der Linienbeschriftungen. Standardmässig 4.

line_label_fontface

Schriftstil der Linienbeschriftungen. Standardmässig "bold".

line_label_hjust

Horizontale Ausrichtung der Linienbeschriftungen. Standardmässig 0.5.

line_label_vjust

Vertikale Ausrichtung der Linienbeschriftungen. Standardmässig -0.5.

line_label_nudge_x

Numerische Verschiebung der Linienbeschriftungen in horizontaler Richtung. Standardmässig 0.

line_label_nudge_y

Numerische Verschiebung der Linienbeschriftungen in vertikaler Richtung. Standardmässig 0.

title

Titel des Diagramms.

subtitle

Untertitel des Diagramms.

source

Quelle der dargestellten Daten. Wird in der Bildunterschrift zusammen mit dem Hinweis auf das Amt für Daten und Statistik Thurgau ausgegeben.

Details

Konfidenzintervalle werden als halbtransparente Flächen um die Linien dargestellt. Die Farben dieser Flächen orientieren sich an den Farben der jeweiligen Linien beziehungsweise Gruppen. Die Gruppierungsreihenfolge kann über eine Sortiervariable gesteuert werden.

Zusätzlich können numerische Werte direkt im Diagramm angezeigt und die einzelnen Linien mit ihren Kategorienamen beschriftet werden. Die Grenzen der vertikalen Achse lassen sich bei Bedarf manuell festlegen.

Value

Ein ggplot-Objekt, das weiter angepasst oder mit print() ausgegeben werden kann.

Examples

## Not run: 
# Liniendiagramm mit Konfidenzintervallen nach Geschlecht
ggplot_line_vi(
  data = tab_erwerbsquote |>
    dplyr::mutate(jahr = as.character(jahr)) |>
    dplyr::filter(sex != "Total"),
  x = "jahr",
  y = "anteil",
  group = "sex",
  group_palette = colors_gender,
  group_palette_name = "fillColor",
  title = "Erwerbsquote nach Geschlecht",
  subtitle = "Entwicklung über die Zeit",
  source = "Kantonale Bevölkerungserhebung",
  ci_lower = "ci_l_pr",
  ci_upper = "ci_u_pr",
  ribbon_alpha = 0.10
)

# Liniendiagramm mit zusätzlichen Linienbeschriftungen
ggplot_line_vi(
  data = tab_erwerbsquote |>
    dplyr::mutate(jahr = as.character(jahr)) |>
    dplyr::filter(sex != "Total"),
  x = "jahr",
  y = "anteil",
  group = "sex",
  group_palette = colors_gender,
  group_palette_name = "fillColor",
  title = "Erwerbsquote nach Geschlecht",
  subtitle = "Entwicklung über die Zeit",
  source = "Kantonale Bevölkerungserhebung",
  ci_lower = "ci_l_pr",
  ci_upper = "ci_u_pr",
  ribbon_alpha = 0.10,
  line_labels = TRUE
)
