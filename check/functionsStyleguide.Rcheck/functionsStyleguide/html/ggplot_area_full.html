ggplot_area_full {functionsStyleguide}R Documentation

Flächendiagramm (Area) gemäss Styleguide

Description

Funktion zur Darstellung von Daten als Flächen- resp. Area-Charts mit ggplot2 gemäss dem Design Styleguide des Amts für Daten und Statistik

Usage

ggplot_area_full(
  data,
  y,
  x,
  group,
  order = NULL,
  group_palette = maincolors_discrete,
  group_palette_name = "fillColor",
  group_colors = NULL,
  group_reverse = FALSE,
  border_palette = border_discrete,
  border_palette_name = "borderColor",
  border_colors = NULL,
  border_reverse = FALSE,
  area_labels = FALSE,
  area_label_position = 0.5,
  area_label_color = "white",
  area_label_size = 4,
  area_label_fontface = "bold",
  area_label_angle = 0,
  area_label_hjust = 0.5,
  area_label_vjust = 0.5,
  area_label_nudge_x = 0,
  area_label_nudge_y = 0,
  title = NULL,
  subtitle = NULL,
  source = NULL
)

Arguments

data

Datensatz, der dargestellt werden soll (vorzugsweise im Long-Format mit je Spalten zu den Kategorien und der Anzahl, je nachdem auch einer Sortierungsvariable)

y

Name der Variable mit den Werten, bspw. Anzahl.

x

Name der Variable, die auf der x-Achse abgebildet werden soll, bspw. Jahreszahl.

group

Name der Variable, deren Kategorien dargestellt werden sollen, z.B. Altersklassen.

order

Optionale Variable für die Sortierung der Kategorien.

group_palette

Palettensammlung für die Flächenfüllung, bspw. maincolors_discrete für die Hauptfarben gemäss Styleguide.

group_palette_name

Name der Palette innerhalb der Palettensammlun, z.B. fillColor für die Hauptfarben oder fillHighlight für Highlightfarben.

group_colors

Optionale Auswahl einer Farbe innerhalb der Palette, bspw. 1 für erste Farbe in der Palette

group_reverse

TRUE ermöglicht eine Umkehrung der Reihenfolge der Palettenfarbe, Default ist FALSE.

border_palette

Palettensammlung für die Randfarbe (Linie oberhalb der jeweiligen Fläche)

border_palette_name

Name der Palette innerhalb der Palettensammlung für die Randfarben

border_colors

Optionale Auswahl einer Farbe innerhalb der Palette, sollte immer der Auswahl über group_colors entsprechen

border_reverse

TRUE ermöglicht eine Umkehrung der Reihenfolge der Palettenfarbe, Default ist FALSE, sollte immer der Definition in group_reverse entsprechen

area_labels

Zeigt die Kategorien-Labels innerhalb der jeweiligen Fläche an.

area_label_position

Relative horizontale Position der Kategorien-Labels.

area_label_color

Farbe der Kategorien-Labels

area_label_size

Schriftgrösse der Kategorien-Labels

area_label_fontface

Schrifttyp der Kategorien-Labels, Default ist "bold" (weitere Optionen: "plain", "italic", "bold.italic")

area_label_angle

Ausrichtung der Kategorien-Labels, Default ist 0 (horizontal)

area_label_hjust

Horizontale Ausrichtung der Labels (negativer Wert: Verschiebung nach rechts, positiver Wert: Verschiebung nach links)

area_label_vjust

Vertikale Ausrichtung der Labels (negativer Wert: Verschiebung nach oben, positiver Wert: Verschiebung nach unten)

area_label_nudge_x

Horizontale Justierung der Kategorien-Labels zum Datenpunkt.

area_label_nudge_y

Vertikale Justierung der Kategorien-Labels zum Datenpunkt.

title

Diagrammtitel

subtitle

Diagrammuntertitel

source

Datenquelle

Value

ggplot Flächen-Diagramm.

#' @examples ## Not run: # ggplot_area_full( data = tab_alterskat, x = "jahr", y = "n", order = "order", group = "alterskat_det", area_labels = TRUE, area_label_size = 4, area_label_nudge_x = 0.2, group_palette = maincolors_discrete, group_palette_name = "fillColor", title = "Bevölkerung nach Alterskategorie", subtitle = "Entwicklung über die Zeit", source = "Kantonale Bevölkerungserhebung", ) ggplot_area_full( data = tab_alterskat, x = "jahr", y = "n", order = "order", group = "alterskat_det", area_labels = TRUE, area_label_size = 4, area_label_position = 0.5, area_label_nudge_x = -1, area_label_nudge_y = -1, group_palette = colors_sequential, group_palette_name = "fillSeq5", border_palette = border_sequential, border_palette_name = "borderSeq5", title = "Bevölkerung nach Alterskategorie", subtitle = "Entwicklung über die Zeit", source = "Kantonale Bevölkerungserhebung" ) ## End(Not run)
