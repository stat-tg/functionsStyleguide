ggplot_grouped_bar {functionsStyleguide}R Documentation

Einfaches gestapeltes Säulendiagramm gemäss Styleguide

Description

Mit dieser Funktion können einfach gestapelte Säulendiagramme mit ggplot gemäss Styleguide erstellt werden

Usage

ggplot_grouped_bar(
  data,
  y,
  x,
  fill = NULL,
  color = NULL,
  title = NULL,
  subtitle = NULL,
  source = NULL,
  fill_color = 1,
  border_color = 1,
  position = "stack"
)

Arguments

y

The second number.

x

The first number.

Value

ggplot bar chart.
