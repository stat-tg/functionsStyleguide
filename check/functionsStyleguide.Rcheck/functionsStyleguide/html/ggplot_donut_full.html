ggplot_donut_full {functionsStyleguide}R Documentation

Vollständiges Donutdiagramm erstellen

Description

Erstellt ein Donutdiagramm mit anpassbaren Farben, Prozentbeschriftungen und einem einstellbaren Startwinkel. Die Daten können optional anhand eines bestimmten Wertes einer Variablen gefiltert werden.

Usage

ggplot_donut_full(
  data,
  filter_value = NULL,
  x,
  y,
  fill_cat,
  hsize,
  title,
  subtitle,
  source,
  order = NULL,
  start_category = NULL,
  start_angle = 0,
  palette = maincolors_discrete,
  palette_name = "fillColor",
  colors = NULL,
  reverse = FALSE,
  label_color = "white",
  label_size = 4.5,
  label_fontface = "bold"
)

Arguments

data

Ein Data Frame mit den darzustellenden Daten.

filter_value

Optionaler Wert, nach dem die Daten gefiltert werden. Der Wert wird mit der Variable x verglichen. Wenn NULL, werden alle Beobachtungen verwendet.

x

Name der Variable, anhand derer die Daten optional gefiltert werden, angegeben als Zeichenkette.

y

Name der numerischen Variable mit den Werten, die durch die Segmente dargestellt werden, angegeben als Zeichenkette.

fill_cat

Name der kategorialen Variable, anhand derer die Segmente eingefärbt werden, angegeben als Zeichenkette.

hsize

Numerischer Wert für die Grösse des inneren Lochs des Donutdiagramms. Wird zur Festlegung der Position und des sichtbaren Innenbereichs verwendet.

title

Titel des Diagramms.

subtitle

Untertitel des Diagramms.

source

Quelle der dargestellten Daten. Wird in der Bildunterschrift zusammen mit dem Hinweis auf das Amt für Daten und Statistik Thurgau ausgegeben.

order

Optionale Variable zur Sortierung der Daten vor der Erstellung des Diagramms, angegeben als Zeichenkette. Die Beobachtungen werden anhand dieser Variable aufsteigend sortiert.

start_category

Optionale Kategorie aus fill_cat, die als erstes Segment dargestellt werden soll. Die übrigen Kategorien folgen anschliessend in ihrer bestehenden Reihenfolge.

start_angle

Numerischer Startwinkel in Grad für das erste Segment. Der Winkel wird modulo 360 Grad umgerechnet. Standardmässig 0. Ein Winkel von 0 Grad entspricht der 12-Uhr-Position, 90 Grad der 3-Uhr-Position, 180 Grad der 6-Uhr-Position und 270 Grad der 9-Uhr-Position.

palette

Farbpalette für die Segmente. Standardmässig wird maincolors_discrete verwendet.

palette_name

Name des Eintrags innerhalb von palette, aus dem die Farben ausgewählt werden. Standardmässig "fillColor".

colors

Optionaler Vektor mit benutzerdefinierten Farben für die Segmente. Wird an scale_fill_custom() übergeben.

reverse

Logischer Wert. Wenn TRUE, wird die Reihenfolge der Farben umgekehrt.

label_color

Farbe der Prozentbeschriftungen innerhalb der Segmente. Standardmässig "white".

label_size

Schriftgrösse der Prozentbeschriftungen. Standardmässig 4.5.

label_fontface

Schriftstil der Prozentbeschriftungen. Zulässige Werte sind "plain", "bold", "italic" und "bold.italic". Standardmässig "bold".

Details

Die Reihenfolge der Segmente kann über eine Sortiervariable und eine Startkategorie gesteuert werden. Die Startkategorie bestimmt, welches Segment zuerst dargestellt wird. Die Prozentwerte werden anhand der Summe der dargestellten Werte berechnet.

Value

Ein ggplot-Objekt, das weiter angepasst oder mit print() ausgegeben werden kann.

Examples

## Not run: 
# Donutdiagramm für ein bestimmtes Jahr
ggplot_donut_full(
  data = tab_alterskat,
  filter_value = "2025",
  x = "jahr",
  y = "n",
  fill_cat = "alterskat_det",
  title = "Bevölkerung nach Alterskategorien",
  subtitle = "Kanton Thurgau, 2025",
  hsize = 1,
  order = "order",
  source = "Kantonale Bevölkerungsstatistik"
)

# Donutdiagramm mit benutzerdefinierter Farbpalette und Startkategorie
ggplot_donut_full(
  data = tab_alterskat,
  filter_value = "2025",
  x = "jahr",
  y = "n",
  fill_cat = "alterskat_det",
  title = "Bevölkerung nach Alterskategorien",
  subtitle = "Kanton Thurgau, 2025",
  hsize = 1,
  order = "order",
  start_category = "unter 25",
  palette = colors_sequential,
  palette_name = "fillSeq5",
  source = "Kantonale Bevölkerungsstatistik"
)

## End(Not run)
