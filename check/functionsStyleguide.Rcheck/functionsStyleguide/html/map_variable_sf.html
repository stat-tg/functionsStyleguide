map_variable_sf {functionsStyleguide}R Documentation

Gemeindekarte mit beschrifteten Gemeinden erstellen

Description

Erstellt eine Karte der Gemeinden des Kantons Thurgau auf Grundlage eines räumlichen sf-Objekts. Die Gemeinden werden anhand der Variable kategorie eingefärbt und mit ihren Namen beschriftet.

Usage

map_variable_sf(gmd_data, angle_data, legend_ncol = 2)

Arguments

gmd_data

Ein räumliches sf-Objekt mit den Gemeindegeometrien. Es muss mindestens die Variable kategorie enthalten, anhand derer die Gemeinden eingefärbt werden.

angle_data

Eine Liste mit vorbereiteten Koordinatendatensätzen für die Gemeindebeschriftungen. Erwartet werden die Elemente coords_0, coords_0_rick, coords_vjust_0, coords_20, coords_45, coords_60, coords_70, coords_295, coords_315 und coords_330. Jeder Datensatz muss mindestens die Variablen X, Y, gemeinde und value enthalten.

legend_ncol

Anzahl der Spalten in der Kartenlegende. Muss eine positive ganze Zahl sein. Standardmässig 2.

Details

Die Position, Drehung sowie horizontale und vertikale Ausrichtung der Gemeindebeschriftungen werden über vorbereitete Koordinatendatensätze gesteuert. Dadurch können die Beschriftungen individuell positioniert werden, um die Lesbarkeit der Karte zu verbessern.

Zusätzlich wird der Bodensee als Hintergrundgeometrie dargestellt. Die Anzahl der Spalten in der Legende kann über legend_ncol festgelegt werden.

Die Hintergrundgeometrie des Bodensees wird aus der Datei "data/maps/Bodensee.shp" geladen. Diese Datei muss unter dem angegebenen relativen Pfad verfügbar sein.

Die Gemeindebeschriftungen werden in mehreren Ebenen hinzugefügt. Je nach Koordinatendatensatz unterscheiden sich Drehwinkel sowie die horizontale und vertikale Ausrichtung der Beschriftungen.

Die Beschriftungsfarbe richtet sich nach der Variable value: Werte ab 3000 werden weiss, kleinere Werte schwarz dargestellt. Die Karten- und Legendenformatierung wird teilweise durch theme_opts_map bestimmt.

Value

Ein ggplot-Objekt mit der Gemeindekarte, den Gemeindebeschriftungen und der Legende.

Examples

## Not run: 
# Gemeindekarte mit zweispaltiger Legende
map_variable_sf(
  gmd_data = gemeinde_sf,
  angle_data = angle_data,
  legend_ncol = 2
)

# Gemeindekarte mit einspaltiger Legende
map_variable_sf(
  gmd_data = gemeinde_sf,
  angle_data = angle_data,
  legend_ncol = 1
)

## End(Not run)
