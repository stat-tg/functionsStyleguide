ggplot_bar_vi {functionsStyleguide}R Documentation

Balkengrafik mit Vertrauensintervallen

Description

Funktion zur Darstellung von Daten mit Vertrauensintervallen als Balkengrafiken mit ggplot2 gemäss dem Design Styleguide des Amts für Daten und Statistik

Usage

ggplot_bar_vi(
  data,
  y,
  x,
  ci_lower = NULL,
  ci_upper = NULL,
  group = NULL,
  title = NULL,
  subtitle = NULL,
  source = NULL,
  fill_palette = maincolors_discrete,
  fill_palette_name = "fillColor",
  fill_color = NULL,
  fill_reverse = FALSE,
  border_palette = border_discrete,
  border_palette_name = "borderColor",
  border_color = NULL,
  border_reverse = FALSE,
  position = "dodge",
  errorbar_width = 0.2,
  x_expand = 0.1,
  y_label_wrap = NULL
)

Arguments

data

Datensatz, der als Balkengrafik dargestellt werden soll

y

Variable, die auf der y-Achse dargestellt werden soll

x

Variable, die auf der x-Achse dargestellt werden soll (bspw. das Jahr)

ci_lower

Optionale variable zur Untergrenze des 95%-Vertrauensintervall

ci_upper

Optionale variable zur Obergrenze des 95%-Vertrauensintervall

group

Optionale kategoriale Variable für die gruppierte Darstellung

title

Titel

subtitle

Untertitel

source

Datenquelle

fill_palette

Palettenobjekt, das die Füllfarben enthält. Standardwert ist maincolors_discrete.

fill_palette_name

Zeichenkette, die den Eintrag der Füllpalette angibt, der verwendet werden soll. Standardwert ist "fillColor".

fill_color

Optionale Indizes zur Auswahl von Farben aus der ausgewählten Füllpalette. Wenn group angegeben wird, müssen genügend Farben ausgewählt werden, um alle Gruppen abzudecken. Ist der Wert NULL, wird der gesamte Paletteneintrag verwendet.

fill_reverse

Logischer Wert. Wenn TRUE, werden die ausgewählten Füllfarben umgekehrt. Standardwert ist FALSE.

border_palette

Palettenobjekt, das die Rahmenfarben enthält. Standardwert ist border_discrete.

border_palette_name

Zeichenkette, die den Eintrag der Rahmenpalette angibt, der verwendet werden soll. Standardwert ist "borderColor".

border_color

Optionale Indizes zur Auswahl von Farben aus der ausgewählten Rahmenpalette. Wenn group angegeben wird, müssen genügend Farben ausgewählt werden, um alle Gruppen abzudecken. Ist der Wert NULL, wird der gesamte Paletteneintrag verwendet.

border_reverse

Logischer Wert. Bei TRUE werden die ausgewählten Rahmenfarben umgekehrt. Standardwert ist FALSE.

position

Zeichenkette zur Angabe der Positionierungsmethode für die Balken: "dodge" oder "stack". Standardwert ist "dodge". Gruppierte Balken mit Konfidenzintervall erfordern dodge.

errorbar_width

Numerischer Wert, der die Breite der Endpunkte des Konfidenzintervalls steuert. Standardwert ist ⁠0,2⁠.

x_expand

Numerischer Anteil, der verwendet wird, um die Obergrenze der numerischen Achse über den maximalen beobachteten Wert hinaus zu erweitern. Standardwert ist ⁠0,10⁠.

y_label_wrap

Optionaler numerischer Wert, der die ungefähre Breite in Zeichen angibt, bei der Kategoriebezeichnungen umgebrochen werden. Bei NULL werden Bezeichnungen nicht umgebrochen.

Details

Die Funktion verwendet theme_bar_grid_vertical() und formatiert die numerische Achse mit einem Apostroph als Tausendertrennzeichen. Die numerische Achse wird am oberen Rand des Diagramms positioniert.

Wenn group angegeben wird, werden die Balken je nach Gruppe unter Verwendung der ausgewählten Füll- und Rahmenpaletten eingefärbt. Wenn keine Gruppierungsvariable angegeben wird, werden eine einzige Füllfarbe und eine einzige Rahmenfarbe verwendet.

Konfidenzintervalle werden gezeichnet, wenn sowohl ci_lower als auch ci_upper angegeben sind. Die Intervallvariablen müssen numerische Unter- und Obergrenzen auf derselben Skala wie x enthalten.

Value

Eine ggplot Balkengrafik mit VIs

Examples

## Not run: 
# Horizontales Balkendiagramm mit Konfidenzintervallen
ggplot_bar_vi(
  data = tab_bildung_tot,
  y = "ausbildung_5cat",
  x = "anteil",
  ci_lower = "ci_l_pr",
  ci_upper = "ci_u_pr",
  title = "Bildung nach Ausbildungsstufe",
  source = "Kantonale Bevölkerungsstatistik",
  fill_color = 2,
  border_color = 2,
  y_label_wrap = 20
)

# Grouped horizontal bars by sex
ggplot_bar_vi(
  data = tab_bildung_sex_full,
  y = "ausbildung_5cat",
  x = "anteil",
  group = "sex",
  ci_lower = "ci_l_pr",
  ci_upper = "ci_u_pr",
  title = "Bildung nach Geschlecht",
  subtitle = "Kanton Thurgau",
  source = "Kantonale Bevölkerungsstatistik",
  y_label_wrap = 20
)

## End(Not run)
