Styleguide palettes

Description

Palettes with the colors according to the Styleguide of the Amt für Daten und Statistik Thurgau (see also file://svmktgaccp01.tg.ch/data$/SK-Daten-und-Prozesse/stat/allgemein/styleguide_qmd/index.html) as well as functions for simple ggplot plots.

Usage

styleguide_palettes

maincolors_discrete

border_discrete

colors_divergent

border_divergent

colors_sequential

border_sequential

colors_gender

border_gender

colors_regions

border_regions

party_colors

Format

styleguide_palettes

An object of class palettes_palette with 62 colour palettes. Use names(styleguide_palettes) to return all palette names.

maincolors_discrete

An object of class palettes_palette with 3 discrete colour palettes for the main 7 colors including colors for segmental charts and highlight colors especially for line charts. Use names(maincolors_discrete) to return all palette names.

border_discrete

An object of class palettes_palette with 3 border colors for the 7 main colors used for bar charts etc. Use names(border_discrete) to return all palette names.

colors_divergent

An object of class palettes_palette with 8 color palettes for divergent categories i.e. categorical data with negative and positive values. Use names(colors_divergent) to return all palette names.

border_divergent

An object of class palettes_palette with 7border color palettes for divergent categories i.e. categorical data with negative and positive values. Use names(border_divergent) to return all palette names.

colors_sequential

An object of class palettes_palette with 9 color palettes for sequential categories i.e. categorical data with ordinal data categories. Use names(colors_sequential) to return all palette names.

border_sequential

An object of class palettes_palette with 9 border color palettes for sequential categories i.e. categorical data with ordinal data categories. Use names(border_sequential) to return all palette names.

colors_gender

An object of class palettes_palette with 4 color palettes for gender categories (men = green color shapes, women = violet color shapes). Use names(colors_gender) to return all palette names.

border_gender

An object of class palettes_palette with 3 border color palettes for gender categories (men = green color shapes, women = violet color shapes). Use names(border_gender) to return all palette names.

colors_regions

An object of class palettes_palette with 10 color palettes for different regional data i.e. Switzerland, Eastern Switzerland, other cantons etc. Use names(colors_regions) to return all palette names.

border_regions

An object of class palettes_palette with 5 border color palettes for different regional data i.e. Switzerland, Eastern Switzerland, other cantons etc. Use names(border_regions) to return all palette names.

party_colors

An object of class palettes_palette with 1 party colors for the main political parties. Use names(party_colors) to return all palette names.
