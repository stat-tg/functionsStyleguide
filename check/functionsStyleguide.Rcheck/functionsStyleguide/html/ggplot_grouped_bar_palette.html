ggplot_grouped_bar_palette {functionsStyleguide}R Documentation

Gruppiertes oder gestapeltes Balkendiagramm mit benutzerdefinierten Farben erstellen

Description

Erstellt ein horizontales Balkendiagramm, bei dem Balken nach einer Kategorie eingefärbt und optional mit kategorienabhängigen Rahmenfarben versehen werden. Die Farbgebung erfolgt über benutzerdefinierte Farbpaletten.

Usage

ggplot_grouped_bar_palette(
  data,
  y,
  x,
  fill = NULL,
  color = NULL,
  order = NULL,
  fill_palette = maincolors_discrete,
  fill_palette_name = "fillColor",
  fill_colors = NULL,
  fill_reverse = FALSE,
  border_palette = border_discrete,
  border_palette_name = "borderColor",
  border_colors = NULL,
  border_reverse = FALSE,
  fill_color = 1,
  border_color = 1,
  title = NULL,
  subtitle = NULL,
  source = NULL,
  position = "stack",
  reverse_stack = TRUE
)

Arguments

data

Ein Data Frame mit den darzustellenden Daten.

y

Zeichenkette mit dem Namen der numerischen Variable für die Balkenlängen.

x

Zeichenkette mit dem Namen der kategorialen Variable für die Kategorienachse.

fill

Optionale Zeichenkette mit dem Namen der Variable, anhand derer die Balkenfüllung kategorisiert wird. Bei NULL wird eine feste Füllfarbe verwendet.

color

Optionale Zeichenkette mit dem Namen der Variable, anhand derer die Rahmenfarben der Balken kategorisiert werden. Bei NULL wird eine feste Rahmenfarbe verwendet.

order

Optionale Zeichenkette mit dem Namen einer Variable, anhand derer die Kategorien von fill sortiert werden. Standardmässig NULL; in diesem Fall wird die Reihenfolge aus den Faktorlevels oder aus dem Auftreten der Kategorien im Datensatz übernommen.

fill_palette

Liste mit Farbpaletten für die Balkenfüllung. Standardmässig maincolors_discrete.

fill_palette_name

Zeichenkette mit dem Namen des Palettenelements, aus dem die Füllfarben ausgewählt werden. Standardmässig "fillColor".

fill_colors

Optionaler Index oder Vektor von Indizes zur Auswahl bestimmter Füllfarben aus dem gewählten Palettenelement. Standardmässig NULL.

fill_reverse

Logischer Wert. Wenn TRUE, wird die Reihenfolge der ausgewählten Füllfarben umgekehrt. Standardmässig FALSE.

border_palette

Liste mit Farbpaletten für die Balkenrahmen. Standardmässig border_discrete.

border_palette_name

Zeichenkette mit dem Namen des Palettenelements, aus dem die Rahmenfarben ausgewählt werden. Standardmässig "borderColor".

border_colors

Optionaler Index oder Vektor von Indizes zur Auswahl bestimmter Rahmenfarben aus dem gewählten Palettenelement. Standardmässig NULL.

border_reverse

Logischer Wert. Wenn TRUE, wird die Reihenfolge der ausgewählten Rahmenfarben umgekehrt. Standardmässig FALSE.

fill_color

Index der Füllfarbe aus dem gewählten Palettenelement, die verwendet wird, wenn fill = NULL. Standardmässig 1.

border_color

Index der Rahmenfarbe aus dem gewählten Palettenelement, die verwendet wird, wenn color = NULL. Standardmässig 1.

title

Optionaler Titel des Diagramms. Standardmässig NULL.

subtitle

Optionaler Untertitel des Diagramms. Standardmässig NULL.

source

Optionale Angabe der Datenquelle. Wird zusammen mit dem Hinweis auf das Amt für Daten und Statistik Thurgau in der Bildunterschrift ausgegeben. Standardmässig NULL.

position

Positionierung der Balken. Bei "stack" werden die Balken gestapelt, bei "dodge" nebeneinander angeordnet. Andere Werte werden direkt an die Positionsberechnung von geom_col() übergeben. Standardmässig "stack".

reverse_stack

Logischer Wert zur Umkehrung der Stapelreihenfolge, wenn position = "stack" verwendet wird. Standardmässig TRUE.

Details

Die Reihenfolge der Füllkategorien kann über eine zusätzliche Sortiervariable gesteuert werden. Die Balken können gestapelt oder nebeneinander angeordnet werden. Bei gestapelten Balken lässt sich zusätzlich die Stapelreihenfolge umkehren.

Wenn fill angegeben ist und order nicht NULL ist, werden die Kategorien anhand der Sortiervariable geordnet. Dazu werden eindeutige Kombinationen der Füllkategorie und der Sortiervariable nach order sortiert. Die resultierende Reihenfolge wird als Faktorstufen für die Füllvariable verwendet.

Wenn color und fill identisch sind, wird dieselbe Kategorienreihenfolge auch für die Rahmenfarben verwendet. Andernfalls richtet sich die Reihenfolge der Rahmenkategorien nach den Faktorlevels oder ihrem Auftreten im Datensatz.

Füll- und Rahmenfarben werden über scale_fill_custom() und scale_colour_custom() zugewiesen. Diese Funktionen müssen im Paket verfügbar sein.

Die numerische Achse wird rechts angeordnet und verwendet Apostrophe als Tausendertrennzeichen. Die Kategorienachse und die Formatierung des Diagramms werden durch theme_bar_grid_vertical und coord_flip() gestaltet.

Value

Ein ggplot-Objekt mit horizontal dargestellten Balken, benutzerdefinierten Füll- und Rahmenfarben sowie formatierter Beschriftung.
