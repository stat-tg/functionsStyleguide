ggplot_stacked_bar {functionsStyleguide}R Documentation

Gestapeltes horizontales Balkendiagramm erstellen

Description

Erstellt ein horizontales Balkendiagramm mit gestapelten Balken auf Basis eines Datensatzes. Die Balken werden anhand einer Kategorie eingefärbt und können zusätzlich über eine separate Variable mit kategorisierten Rahmenfarben versehen werden.

Usage

ggplot_stacked_bar(
  data,
  y,
  x,
  fill,
  colour,
  title,
  subtitle,
  source,
  order_by = NULL,
  decreasing = FALSE,
  reverse_fill = NULL,
  reverse_color = NULL
)

Arguments

data

Ein Data Frame mit den darzustellenden Daten.

y

Zeichenkette mit dem Namen der Variable für die y-Achse. Diese Variable wird als diskrete Achse dargestellt.

x

Zeichenkette mit dem Namen der numerischen Variable für die x-Achse.

fill

Zeichenkette mit dem Namen der Variable, anhand derer die Balkenfüllung kategorisiert wird.

colour

Zeichenkette mit dem Namen der Variable, anhand derer die Rahmenfarben der Balken kategorisiert werden.

title

Titel des Diagramms.

subtitle

Untertitel des Diagramms.

source

Angabe der Datenquelle. Wird zusammen mit dem Hinweis auf das Amt für Daten und Statistik Thurgau in der Bildunterschrift ausgegeben.

order_by

Optionale Zeichenkette mit dem Namen einer Variable, anhand derer die Kategorien von fill sortiert werden. Standardmässig NULL; in diesem Fall wird die ursprüngliche Kategorienreihenfolge beibehalten.

decreasing

Logischer Wert. Wenn TRUE, wird die anhand von order_by ermittelte Reihenfolge umgekehrt. Wird nur verwendet, wenn order_by nicht NULL ist. Standardmässig FALSE.

reverse_fill

Optionaler logischer Wert zur Umkehrung der Füllfarbskala. Wird an scale_fill_maincolors() übergeben. Standardmässig NULL.

reverse_color

Optionaler logischer Wert zur Umkehrung der Rahmenfarbskala. Wird an scale_colour_main_borders() übergeben. Standardmässig NULL.

Details

Die Reihenfolge der Kategorien kann optional anhand einer weiteren Variable festgelegt werden. Über decreasing lässt sich diese Reihenfolge umkehren. Die Füll- und Rahmenfarben werden über die benutzerdefinierten Farbskalen scale_fill_maincolors() und scale_colour_main_borders() zugewiesen.

Wenn order_by angegeben ist, wird die Reihenfolge der Kategorien anhand der eindeutigen Kombinationen der Variablen fill und order_by bestimmt. Die Daten werden nach order_by sortiert und die resultierende Reihenfolge wird als Faktorstufen für die Variablen fill und colour verwendet. Daher sollten die Kategorien beider Variablen zueinander passen.

Die x-Achse wird oberhalb des Diagramms angezeigt und verwendet Tausendertrennzeichen mit Apostrophen. Beide Achsen erhalten keinen zusätzlichen Rand. Die Formatierung wird durch theme_bar_grid_vertical ergänzt.

Die Legenden für Füllung und Rahmenfarbe werden unabhängig von den Farbskalen jeweils in umgekehrter Reihenfolge dargestellt.

Value

Ein ggplot-Objekt mit gestapelten horizontalen Balken, benutzerdefinierten Farbskalen und formatierter Beschriftung.

Examples

## Not run: 
ggplot_stacked_bar(
  data = tab_alterskat |>
    dplyr::mutate(jahr = as.character(jahr)),
  y = "jahr",
  x = "n",
  fill = "alterskat_det",
  colour = "alterskat_det",
  title = "Bevölkerung wird älter",
  subtitle = paste(
    "Kanton Thurgau, Ständige Wohnbevölkerung",
    "nach Altersklassen, 2015–2025"
  ),
  source = "Kantonale Bevölkerungsstatistik",
  order_by = "order",
  decreasing = TRUE,
  reverse_fill = TRUE,
  reverse_color = TRUE
)

## End(Not run)
