ggplot_dumbbell {functionsStyleguide}R Documentation

Dumbbell-Diagramm zum Vergleich zweier Zeitpunkte erstellen

Description

Erstellt ein Dumbbell-Diagramm, um die Werte einer Variable für zwei ausgewählte Zeitpunkte miteinander zu vergleichen. Für jede Kategorie werden die beiden Werte als Punkte dargestellt und durch eine Linie verbunden. Dadurch lassen sich Veränderungen zwischen den Zeitpunkten auf einen Blick erkennen.

Usage

ggplot_dumbbell(
  data,
  x,
  y,
  x_min,
  x_max,
  source,
  title = NULL,
  subtitle = NULL,
  label = NULL,
  label_colour = "black",
  label_size = 4,
  label_nudge_x = 0,
  label_nudge_y = 0,
  x_expand = 0.2
)

Arguments

data

Ein Data Frame mit den darzustellenden Daten. Erwartet werden mindestens die Variablen jahr, die Vergleichsvariable sowie die Kategorievariable.

x

Zeichenkette mit dem Namen der numerischen Variable, deren Werte zwischen den beiden Zeitpunkten verglichen werden.

y

Zeichenkette mit dem Namen der Kategorievariable, beispielsweise Gemeindenamen.

x_min

Zeichenkette mit dem ersten zu vergleichenden Zeitpunkt, beispielsweise "2025". Muss als Wert in der Variable jahr vorkommen.

x_max

Zeichenkette mit dem zweiten zu vergleichenden Zeitpunkt, beispielsweise "2026". Muss als Wert in der Variable jahr vorkommen.

source

Angabe der Datenquelle. Wird zusammen mit dem Hinweis auf das Amt für Daten und Statistik Thurgau in der Bildunterschrift ausgegeben.

title

Optionaler Titel des Diagramms. Standardmässig NULL.

subtitle

Optionaler Untertitel des Diagramms. Standardmässig NULL.

label

Optionaler Name einer Variable mit den Beschriftungen für die beiden Vergleichspunkte. Bei NULL werden keine Beschriftungen hinzugefügt. Die Variable wird anhand der Werte in jahr und der Kategorievariable den Punkten zugeordnet.

label_colour

Farbe der Beschriftungen. Bei "point" übernehmen die Beschriftungen die Farben der jeweiligen Punkte. Andernfalls wird die angegebene feste Farbe verwendet. Standardmässig "black".

label_size

Grösse der Beschriftungen. Standardmässig 4.

label_nudge_x

Horizontale Verschiebung der Beschriftungen. Standardmässig 0.

label_nudge_y

Vertikale Verschiebung der Beschriftungen. Standardmässig 0.

x_expand

Relativer Zuschlag zum maximalen dargestellten Wert, um zusätzlichen Platz am oberen Ende der Wertachse zu schaffen. Beispielsweise entspricht 0.20 einem Zuschlag von 20 Prozent. Standardmässig 0.20.

Details

Die beiden Zeitpunkte werden über x_min und x_max ausgewählt. Die Punkte werden mit unterschiedlichen Farben aus colors_regions dargestellt. Optional können die Werte direkt beschriftet werden. Die Beschriftungen können entweder die Farben der zugehörigen Punkte übernehmen oder in einer festen Farbe angezeigt werden.

Die Funktion filtert den Datensatz auf die beiden ausgewählten Zeitpunkte und bringt die Werte anschliessend in ein breites Datenformat, sodass für jeden Zeitpunkt eine eigene Spalte entsteht. Fehlt einer der angegebenen Zeitpunkte im resultierenden Datensatz, wird ein Fehler ausgelöst.

Die Verbindungslinien verwenden die Farbe colors_regions$fillKantoneLine. Die Punkte für x_min und x_max verwenden die Farben colors_regions$fillOstschweizLine beziehungsweise colors_regions$fillSchweizLine.

Die Wertachse wird oberhalb des Diagramms positioniert und beginnt bei null. Die obere Grenze wird anhand des maximalen Wertes beider Zeitpunkte und des Parameters x_expand berechnet.

Wenn label angegeben ist, wird die entsprechende Variable für beide ausgewählten Zeitpunkte aus den ursprünglichen Daten übernommen und als Punktbeschriftung verwendet.

Value

Ein ggplot-Objekt mit den Verbindungslinien, den beiden Vergleichspunkten pro Kategorie, einer Legende für die Zeitpunkte und optionalen Wertbeschriftungen.

Examples

## Not run: 
ggplot_dumbbell(
  data = tab_steuerfuss_change_long,
  x = "gemeindesteuerfuss",
  y = "gemeinde_name",
  x_min = "2025",
  x_max = "2026",
  source = "Steuerverwaltung Thurgau",
  title = "Steuerfuss der Gemeinden",
  subtitle = "Veränderung zwischen 2025 und 2026",
  label = "gemeindesteuerfuss",
  label_colour = "point",
  label_size = 4
)

## End(Not run)
