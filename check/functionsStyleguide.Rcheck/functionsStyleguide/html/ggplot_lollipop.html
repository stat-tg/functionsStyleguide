ggplot_lollipop {functionsStyleguide}R Documentation

Lollipop-Diagramm erstellen

Description

Erstellt ein Lollipop-Diagramm zur Darstellung numerischer Werte nach Kategorien. Jeder Wert wird durch einen Punkt dargestellt, der über eine vertikale Linie mit dem Nullpunkt verbunden ist. Durch die Verwendung von coord_flip() werden die Kategorien horizontal und die Werte auf einer horizontalen Achse dargestellt.

Usage

ggplot_lollipop(
  data,
  x,
  y,
  title,
  subtitle,
  source,
  size_point = 4,
  y_expand = 0.1,
  label = NULL,
  label_colour = "black",
  label_size = 4,
  label_nudge_y = 0.5,
  label_fontface = "bold",
  fill_palette = maincolors_discrete,
  fill_palette_name = "fillColor",
  fill_colors = 1,
  fill_reverse = FALSE,
  border_palette = border_discrete,
  border_palette_name = "borderColor",
  border_colors = 1,
  border_reverse = FALSE
)

Arguments

data

Ein Data Frame mit den darzustellenden Daten.

x

Zeichenkette mit dem Namen der kategorialen Variable für die Kategorienachse, beispielsweise Gemeindenamen.

y

Zeichenkette mit dem Namen der numerischen Variable, deren Werte dargestellt werden sollen.

title

Titel des Diagramms.

subtitle

Untertitel des Diagramms.

source

Angabe der Datenquelle. Wird zusammen mit dem Hinweis auf das Amt für Daten und Statistik Thurgau in der Bildunterschrift ausgegeben.

size_point

Grösse der Punkte im Diagramm. Standardmässig 4.

y_expand

Relativer Zuschlag zum maximalen Wert von y, um zusätzlichen Platz am oberen Ende der Wertachse zu schaffen. Beispielsweise entspricht 0.10 einem Zuschlag von 10 Prozent. Standardmässig 0.10.

label

Logischer Wert, der angibt, ob die Werte beschriftet werden sollen. Bei TRUE werden die Werte der Variable y neben den Punkten angezeigt. Standardmässig NULL, wodurch keine Beschriftungen hinzugefügt werden.

label_colour

Farbe der Beschriftungen. Bei "point" wird die Füllfarbe der Punkte verwendet; andernfalls kann eine feste Farbe angegeben werden. Standardmässig "black".

label_size

Grösse der Wertbeschriftungen. Standardmässig 4.

label_nudge_y

Abstand der Beschriftungen in Richtung der Wertachse. Wird an geom_text() als nudge_y übergeben. Standardmässig 0.5.

label_fontface

Schriftstil der Beschriftungen, beispielsweise "plain" oder "bold". Standardmässig "bold".

fill_palette

Liste mit Farbpaletten für die Punktfüllung. Standardmässig maincolors_discrete.

fill_palette_name

Zeichenkette mit dem Namen des Palettenelements, aus dem die Füllfarben ausgewählt werden. Standardmässig "fillColor".

fill_colors

Optionaler Index oder Vektor von Indizes zur Auswahl bestimmter Farben aus dem gewählten Füllfarben-Palettenelement. Verwendet wird die erste ausgewählte Farbe. Bei NULL wird die gesamte Palette berücksichtigt. Standardmässig 1.

fill_reverse

Logischer Wert. Wenn TRUE, wird die Reihenfolge der ausgewählten Füllfarben umgekehrt. Standardmässig FALSE.

border_palette

Liste mit Farbpaletten für die Punktränder. Standardmässig border_discrete.

border_palette_name

Zeichenkette mit dem Namen des Palettenelements, aus dem die Rahmenfarben ausgewählt werden. Standardmässig "borderColor".

border_colors

Optionaler Index oder Vektor von Indizes zur Auswahl bestimmter Farben aus dem gewählten Rahmenfarben-Palettenelement. Verwendet wird die erste ausgewählte Farbe. Bei NULL wird die gesamte Palette berücksichtigt. Standardmässig 1.

border_reverse

Logischer Wert. Wenn TRUE, wird die Reihenfolge der ausgewählten Rahmenfarben umgekehrt. Standardmässig FALSE.

Details

Die Füll- und Rahmenfarben der Punkte werden aus benutzerdefinierten Farbpaletten ausgewählt. Optional können die dargestellten Werte direkt neben den Punkten beschriftet werden. Der obere Achsenbereich wird automatisch anhand des maximalen Wertes und des Parameters y_expand festgelegt.

Die Linien der Lollipops beginnen beim Wert null und enden beim jeweiligen Wert der Variable y. Die Wertachse wird nach rechts verschoben und reicht von null bis zum maximalen Wert multipliziert mit 1 + y_expand. Der Achsenbereich wird ohne zusätzlichen Rand dargestellt.

Die Punktfüllung und der Punktrand verwenden jeweils die erste Farbe, die nach Auswahl und gegebenenfalls Umkehrung der entsprechenden Palette verfügbar ist. Die übrigen ausgewählten Farben werden nicht verwendet.

Wenn label = TRUE gesetzt ist, werden die Werte der Variable y beschriftet. Mit label_colour = "point" wird dafür die Füllfarbe der Punkte verwendet; andernfalls wird die angegebene feste Beschriftungsfarbe eingesetzt.

Value

Ein ggplot-Objekt mit den Lollipop-Linien, den Punkten, optionalen Wertbeschriftungen und der formatierten Achsen- und Diagrammbeschriftung.

ggplot_lollipop(

  subtitle = "Kanton Thurgau",
  source = "Steuerverwaltung Thurgau",
  size_point = 6,
  fill_palette = colors_gender,
  fill_palette_name = "fillColor",
  fill_colors = 2,
  border_palette = border_gender,
  border_palette_name = "borderColor",
  border_colors = 2,
  label = TRUE,
  label_colour = "point",
  label_size = 4
)
