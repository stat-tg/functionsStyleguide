ggplot_bar_full {functionsStyleguide}R Documentation

Vollständiges horizontales Balkendiagramm erstellen

Description

Erstellt ein horizontales Balkendiagramm mit anpassbaren Füll- und Randfarben, optionaler Gruppierung nach Kategorien sowie Zahlenbeschriftungen. Die Balken können gestapelt oder gruppiert dargestellt werden.

Usage

ggplot_bar_full(
  data,
  y,
  x,
  fill = NULL,
  color = NULL,
  order = NULL,
  fill_palette = maincolors_discrete,
  fill_palette_name = "fillColor",
  fill_colors = NULL,
  fill_reverse = FALSE,
  border_palette = border_discrete,
  border_palette_name = "borderColor",
  border_colors = NULL,
  border_reverse = FALSE,
  fill_color = 1,
  border_color = 1,
  labels = FALSE,
  label_color = "white",
  label_size = 4.5,
  label_fontface = "bold",
  title = NULL,
  subtitle = NULL,
  source = NULL,
  position = "stack",
  reverse_stack = TRUE
)

Arguments

data

Ein Data Frame mit den darzustellenden Daten.

y

Name der numerischen Variable für die Balkenlängen als Zeichenkette.

x

Name der kategorialen Variable auf der Achse als Zeichenkette.

fill

Optionale Variable für die Füllfarben der Balken als Zeichenkette. Wenn NULL, wird eine einheitliche Füllfarbe verwendet.

color

Optionale Variable für die Randfarben der Balken als Zeichenkette. Wenn NULL, werden die Randfarben anhand von fill bestimmt. Ist auch fill gleich NULL, wird eine einheitliche Randfarbe verwendet.

order

Optionale Variable zur Festlegung der Reihenfolge der Füllkategorien als Zeichenkette. Die Kategorien werden entsprechend dieser Variable aufsteigend sortiert.

fill_palette

Palette für die Füllfarben. Standardmässig wird maincolors_discrete verwendet.

fill_palette_name

Name der innerhalb von fill_palette zu verwendenden Farbpalette. Standardmässig "fillColor".

fill_colors

Optionaler benannter Vektor mit individuellen Füllfarben für Kategorien. Wird an scale_fill_custom() übergeben.

fill_reverse

Logischer Wert. Wenn TRUE, wird die Reihenfolge der Füllfarben umgekehrt.

border_palette

Palette für die Randfarben. Standardmässig wird border_discrete verwendet.

border_palette_name

Name der innerhalb von border_palette zu verwendenden Farbpalette. Standardmässig "borderColor".

border_colors

Optionaler benannter Vektor mit individuellen Randfarben für Kategorien. Wird an scale_colour_custom() übergeben.

border_reverse

Logischer Wert. Wenn TRUE, wird die Reihenfolge der Randfarben umgekehrt.

fill_color

Index der Füllfarbe innerhalb der gewählten Füllpalette, wenn keine Variable für die Füllfarben angegeben wurde.

border_color

Index der Randfarbe innerhalb der gewählten Randpalette, wenn weder eine Variable für die Randfarben noch eine Füllvariable vorhanden ist.

labels

Logischer Wert. Wenn TRUE, werden die Werte der numerischen Variable innerhalb oder an den Balken angezeigt.

label_color

Farbe der Zahlenbeschriftungen. Standardmässig "white".

label_size

Schriftgrösse der Zahlenbeschriftungen. Standardmässig 4.5.

label_fontface

Schriftstil der Zahlenbeschriftungen, beispielsweise "bold" oder "plain".

title

Titel des Diagramms.

subtitle

Untertitel des Diagramms.

source

Quelle der dargestellten Daten. Wird in der Bildunterschrift zusammen mit dem Hinweis auf das Amt für Daten und Statistik Thurgau ausgegeben.

position

Positionierung der Balken. Zulässige Werte sind "stack" für gestapelte Balken und "dodge" für nebeneinander dargestellte Balken. Standardmässig "stack".

reverse_stack

Logischer Wert. Steuert bei gestapelten Balken die Reihenfolge der Kategorien. Standardmässig TRUE.

Details

Die Variable x wird bei Bedarf in einen Faktor umgewandelt, damit numerische Werte wie Jahre als diskrete Kategorien dargestellt werden. Die Reihenfolge der Füllkategorien kann über order gesteuert werden.

Value

Ein ggplot-Objekt, das weiter angepasst oder mit print() ausgegeben werden kann.

Examples

## Not run: 
# Einfaches Balkendiagramm
ggplot_bar_full(
  data = tab_bev,
  y = "n",
  x = "jahr",
  title = "Bevölkerungsentwicklung",
  subtitle = "Bevölkerung nach Jahr",
  source = "Kantonale Bevölkerungserhebung",
  labels = TRUE
)

# Gestapelte Balken nach Alterskategorie
ggplot_bar_full(
  data = tab_alterskat,
  y = "n",
  x = "jahr",
  fill = "alterskat_det",
  fill_palette = colors_sequential,
  fill_palette_name = "fillSeq5",
  position = "stack",
  labels = TRUE
)

# Gruppierte Balken nach Alterskategorie
ggplot_bar_full(
  data = tab_alterskat,
  y = "n",
  x = "jahr",
  fill = "alterskat_det",
  fill_palette = colors_sequential,
  fill_palette_name = "fillSeq5",
  position = "dodge"
)

## End(Not run)
